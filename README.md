# 速度工具箱 SuduBox · v1.1.1

**[在线使用 · GitHub Pages](https://suducat.github.io/SuduBox/)** · [手机安装说明](docs/PAGES.md)

**[下载 Mac 版本](https://github.com/suducat/SuduBox/releases/tag/v1.1.0)** · [更新日志](CHANGELOG.md)

平时学习，总有一些小麻烦：看课表、找公式、记作业、算成绩。速度工具箱把这些常用功能放在一起，打开就能用。

面向 AP、A-Level 等国际课程学生的轻量学习与效率工具箱。无需账号、后端或 AI API，学习数据保存在当前浏览器，本地处理，无运行时 CDN 或 Google Fonts。

## 已实现功能

- **AIP GPA 计算器**：荣誉课程、预备课程和中方课程三类最高 4.3 绩点，学校字母等级优先，保留原分数与差异提示。课程目录自动填充已核实学分；支持成绩记录、加权 GPA、批量预览去重、独立模拟和 JSON 备份。政策适用 2023 年秋季及以后入学，结果以学校成绩单为准。

计算设置只保留年级和课程体系按钮，无需填写学年、成绩阶段或存储模式。Psychology 支持英文、psych 和“心理学”搜索，按用户确认自动使用 1 学分。未收录课程的学分仍需填写。原有成绩、历史及备份数据继续保留。

当前开发版已简化 GPA 操作：添加课程只需搜索名称和输入成绩（`98`、`88/A-` 或 `A-`），也可直接粘贴多门成绩。分数在列表中直接修改，快速估算草稿自动保存；需明确确认才能保存或更新正式学期成绩。计算设置会记住，首次会读取已有 AIP 年级和课程路径。学分、类别和等级调整在课程详情中，历史、统计及模拟按需展开。统一 JSON 备份同时包含正式成绩、草稿和计算设置。详见 [改版验收记录](docs/GPA-UX-QA.md)；上方 Release 链接仍指向已发布的 v1.1.0 安装包。

- **工作台与课表**：当前课程、下一节课、今日进度；固定每周课表的添加、编辑、复制和冲突提醒；按具体课程日期保存课堂速记，汇总“没听懂”的知识点，课堂作业可转为便签。
- **AIP 课表**：课表页面通过“我是 AIP 学生”选择年级、班级和选课池，一次选择应用到整周；未选课程时段显示自习。提供高一、高二、高三的本地预设，导入前预览并确认，可保留恢复点；支持时区与日期特殊安排。预设有来源日期，不保证学校后续调课自动同步。
- **便签与考试**：便签自动保存、置顶、完成和搜索；自定义考试倒计时、历史与首页固定，另有注明来源和适用范围的官方考试预设。
- **专注番茄钟**：自定义时长、暂停继续、刷新恢复、实际计时时长记录及统计；完成后由用户确认保存。
- **单词本**：多词库、搜索筛选、批量解析预览和去重、翻卡复习、掌握标记、CSV/JSON 导出及可选设备发音。
- **抽题与文本整理**：题号范围、列表和题答卡片，无重复抽取；可独立开关的保守文本清洗、对比、复制和撤销。
- **学术公式**：41 条数学、物理与经济学公式，提供变量、条件、示例、分类搜索、收藏和自测隐藏；内容不代表完整官方课程。
- **音乐角落**：首页独立卡片，复用已有文案，每 30 秒随机切换且不连续重复，显示歌手与歌曲名称；支持“下一句”、关闭及在设置中重新显示。
- **新手向导与关于**：首次打开显示五步向导，可跳过、返回及在设置中再次查看；关于页整合 suducat 的本地头像、GitHub、联系方式和版本说明。
- **通用能力**：全局工具搜索、常用工具固定、响应式布局、深色模式、数据备份恢复和 PWA 离线缓存。

## 尚未实现

文件格式转换、AI 写作检测提供“敬请期待”页面；当前不转换文件、不调用外部检测服务、不输出 AI 率。复杂 A/B Day、单双周、账号及云同步也未实现。

## 技术栈与结构

Vite + TypeScript + React，使用 lucide-react 图标与本地打包的 KaTeX。React 用于维护表单和跨页面数据，不引入大型 UI 库或复杂状态管理。Hash 路由和相对资源路径适合静态托管。

`src/pages` 存放页面，`src/components` 存放共享组件，`src/data` 存放公式和课表等静态内容，`src/db` 管理 IndexedDB，`src/utils` 存放业务纯函数及测试，`src/styles` 管理统一样式，`src/types` 定义数据类型，`src/tools` 保留工具扩展位置。

## 本地运行（macOS）

安装 Node.js **22.12 或更新的 LTS**（自带 npm），然后在终端进入项目目录：

```bash
cd SuduBox
npm ci
npm run dev
```

浏览器打开终端显示的地址，默认 `http://localhost:5173`。

```bash
npm run typecheck             # 类型检查
npm test                      # 单元测试
npm run build                 # 类型检查并生成 dist/
npm run preview               # 预览构建结果，默认端口 4173
node scripts/check-offline.mjs # 构建后检查缓存策略（模拟环境）
```

## 数据与隐私

课程、课堂记录、便签、考试、单词、专注记录及收藏保存在 IndexedDB；少量偏好保存在 localStorage。没有服务器或跨设备云同步，不上传学习内容。课表预设含课程、教师及教室信息，未导入学生名单；原始 Excel 不属于运行依赖。

更换浏览器、设备或访问地址，以及清除网站数据，可能使记录不可访问或丢失。请在设置的“数据备份与恢复”中定期导出 JSON，并妥善保存，勿将个人备份提交到代码仓库。恢复会校验格式与版本，并在确认后覆盖；失败不会先清空原数据。数据库及备份格式当前为版本 1，未来升级需显式迁移。

## 静态构建与 PWA

`npm run build` 的 `dist/` 可独立托管，无需后端。使用时需上传全部构建文件，并配置 HTTPS。PWA 在首次完整加载和缓存激活后尽量支持离线；浏览器可能回收缓存。直接双击 `file://` 不具备完整 PWA 能力。

推送 main 后，GitHub Actions 自动测试、构建并部署 GitHub Pages，也支持手动重新部署。路径从真实 Pages 配置读取；Mac 构建保持原相对路径。当前验收见 [v1.1.0 验收记录](docs/V1.1.0-QA.md)，历史记录见 [QA.md](QA.md) 和 [ROUND2.md](ROUND2.md)，学习内容范围与来源见 [内容来源](docs/CONTENT-SOURCES.md)。

## macOS 桌面版

项目包含 Tauri 2 封装，保留原有网页版。开发机安装 Rust 和 Xcode Command Line Tools 后执行 `npm run desktop:build`；成功后输出到 `release/macos/`。最终使用者无需 Node.js、终端或本地服务器。首版面向 Apple Silicon / macOS 14+，采用本机测试签名，未经过 Apple 公证。网页版与桌面版的数据通过原 JSON 备份迁移，详情见 [桌面版说明](docs/MACOS.md)。

从上方 Release 下载 `SuduBox-1.1.0-macos-arm64.dmg`，打开后将“速度工具箱”拖进 Applications，再从应用程序打开。分享整个 DMG 即可，同学无需安装 Node.js 或运行命令。仅支持 M 系列 / macOS 14+，尚无 Intel 安装包。未获 Apple Developer 身份签名或公证，其他电脑可能出现 Gatekeeper 提示；确认来源后按 macOS“隐私与安全性”提示处理，不要关闭系统安全保护。

## v1.1.0 使用说明

音乐角落增加“下一句”，手动切换后重新等待 30 秒自动轮换。新手向导改为五步，可返回、跳过和在设置重开。作者与关于页面已合并，旧作者链接会跳转。新猫咪 Logo 用于网页、PWA 和 Mac 图标。

GPA 成绩保存在现有 IndexedDB，包含在全量 JSON 备份内。旧备份不含成绩仍可恢复；恢复覆盖前请核对内容。政策截图及真实学生成绩不随项目分发，评分和课程配置依据见 [GPA 政策说明](docs/GPA-POLICY.md)。必要资源本地打包，GitHub 等外部链接需要联网。

## 手机与平板

iPhone / iPad 用 Safari 打开在线网址，分享 → 添加到主屏幕。Android 可在“关于”中点击浏览器支持的安装按钮，或通过浏览器菜单安装；无需安装也能使用。首次完整加载并缓存后，本地学习工具可离线使用，缓存可能被系统回收。新版只显示提示，不强制刷新；不同设备不自动同步，请定期导出 JSON。详见 [Pages 与 PWA 说明](docs/PAGES.md)。
