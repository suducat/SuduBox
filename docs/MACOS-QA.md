# macOS 桌面验收记录

日期：2026-11-06。环境：Apple Silicon，macOS 15.6.1，Tauri 2；目标最低 macOS 14。

## 已实际执行

- 网页构建、TypeScript 检查和 59 项单元测试通过；覆盖原业务逻辑、备份校验和 IndexedDB 事务，以及新增的桌面保存成功、取消、失败、剪贴板写入和跳过 Service Worker。
- 使用 Rust stable 编译 release 原生 arm64 程序，生成 APP；本机 ad-hoc 签名的严格校验通过。未使用 Apple Developer 身份签名，未公证。
- 删除临时下载配置并停止辅助服务后，使用缓存依赖执行 `CARGO_NET_OFFLINE=true npm run desktop:build`，再次成功生成 APP/DMG，证明后续打包不依赖临时下载服务。
- 最终输出目录 `release/macos/`，APP 和 DMG 均已生成。DMG 使用系统 hdiutil 创建，完整性校验通过；只读挂载后确认包含 APP 和指向 `/Applications` 的链接。
- 独立 APP 已实际启动，页面来源为 `tauri://localhost`，使用内嵌资源，不是 localhost HTTP 开发页。
- 在空白桌面数据空间创建一门验收课程、一张中英文本便签、一个单词；通过菜单退出并从交付目录重新启动 APP，课程、便签、单词和暂停计时器均保留。
- 启动、暂停、重启恢复番茄钟，提前完成后保存实际 6 秒专注记录，暂停和关闭应用的时间未额外计入。
- 实际导出 JSON 经原生保存对话框写入文件；检查备份含课程、便签、单词、专注记录各一条，计时器已清除。通过桌面文件选择器重新导入该同一份完整备份，确认界面显示四条记录并执行恢复，成功提示且记录数量仍为四。
- 检查主要导航、课表录入、便签自动保存、单词录入、番茄钟、备份恢复、主题切换、KaTeX 公式字体及图标显示。

## 限制与说明

- 首次 Tauri DMG 的 Finder 自动排版超时，改为标准只读 DMG；保留 Applications 拖拽安装链接，无需 Finder 自动化权限。
- Tauri 配置宏对存储标识出现数组类型错误，改用 Rust 窗口构造 API 设置同一固定标识；不更改数据库名称、版本或结构。
- 系统文件选择器的自动化曾超时，随后通过键盘导航完成实际导入与恢复。
- 未在 Intel Mac、其他 macOS 版本或同学的设备上实测，也未完成 Apple 公证或真实断开整台电脑网络的长时间验收。资源内嵌与本地页面启动已验证。
- 未穷举原项目全部功能。可选语音和通知能力由系统支持决定。
- 本机桌面空间保留四条明确标记的验收记录与 Documents 中的验收备份，未删除或重置数据库；这些内容不在源码、APP 或 DMG 中，不会分享给其他安装者。网页版数据未读写。
