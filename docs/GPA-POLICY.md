# AIP GPA 规则依据

依据用户于 2026-11-07 提供的 Course Information and Grading Policies 截图：课程定义、Grading Scale、GPA Calculation 与 AP / A Level Course List（目录第 8–14 页）。适用 2023 年秋季及以后入学，截图未标注修订日期；学校保留调整权。原图含姓名水印，不纳入仓库或安装包。项目只整理必要规则和课程字段，没有学生成绩或学校登录信息。

规则配置：`src/data/gpa-policy.ts`；课程和两个学期学分：`src/data/gpa-courses.ts`；计算：`src/utils/gpa.ts`。

- 最高 4.3；P、H、CH 使用独立百分制门槛。先换算再按学分加权，不提前四舍五入；显示保留两位小数。
- 学校字母等级优先，保留百分制原分数，差异明确提示。不推断额外 Curved Grade 算法。
- H 自动换算没有 D-。若学校给出 D-，仍保留用户确认的学校等级，并提示差异。
- CH 学术课程计入；非学术和 College Readiness 按 Pass/Fail 排除。零学分、空成绩不进入分母，有效零分参与。
- 第一期中是阶段估算，不与最终成绩平均，也不加入学年或累计。累计按所有有效最终课程总学分加权。
- 目录不代表学生实际修读；AP Accel / Prep 的必修组合需按实际选课确认。2024 入学条件单独标注。未匹配课程默认零学分，需核实后确认。
- 官方示例为 A- × 1、A- × 0.5、B+ × 0.5，得到 7.20 / 2.00 = 3.60，已加入测试。截图部分原分数旁字母标签与换算表不一致，使用明确的调整后等级，不复制不一致的原标签。

结果仅作学习规划参考，不是学校认证成绩单。政策或课程目录变更后需更新配置和边界测试。

补充课程选项位于 `src/data/gpa-supplement.ts`。AP Psychology 在已提供的 AIP 课表中出现，按政策中 AP 课程使用荣誉课程规则。用户于 2026-11-08 确认其学分为 1，选择和批量导入时自动使用此值。中方课程在数据中继续使用原 CH 代码以兼容历史备份，界面统一显示中文。
