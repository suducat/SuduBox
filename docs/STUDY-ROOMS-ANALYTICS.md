# 自习室查询与匿名统计

## 课表来源和更新

本次使用用户上传的 `高二课表20261008(2).xlsx`，数据版本为 2026-10-08。
`S2` 提供课时；`自习室表2026年10月起 (2)` 提供教室占用。

- 17 间教室，周一至周五每天 10 个时段（1–5、Lunch、6–9），共核对 850 个状态。
- 空白为可用，所有非空内容（包括 `/`、多行文字、Lunch）均为占用。
- 先展开合并区域，再判断空白。午休列中 5302 至 5603 共 9 间教室属于合并的 Lunch 占用区域，不能将合并区域的后续行当作空白。
- JSON 只保留教室、时间、可用布尔值、数据版本及核验信息，不包含任课教师或课程内容；不提交原始工作簿。

独立数据文件：`src/data/study-rooms.json`。未来更新时使用 Python 标准库脚本，无需安装 Excel 解析包：

```sh
python scripts/extract-study-rooms.py '/path/to/高二课表20261008(2).xlsx'
python scripts/extract-study-rooms.py '/path/to/高二课表20261008(2).xlsx' --check
npm test
npm run build
node scripts/check-offline.mjs
```

脚本遇到变化的教室范围、列范围、表头、课时冲突或缺少缓存结果的公式会停止，要求维护者先复核，避免静默漏掉新增数据。原文件 SHA-256 记录在 JSON 的 `sourceSha256` 中。

## 时间规则和尚未明确的信息

使用设备系统时刻换算为 UTC+8，不受设备显示时区或用户个人课表设置影响。
每个时段采用 `[开始, 结束)`：结束瞬间切换至课间/下一时段。挂载立即计算，每 15 秒、重新聚焦或恢复可见时更新，默认自动查询；也可切换为手动查询。

- 周一首节 08:10–08:50，周二至周五首节 08:00–08:40；其余课时使用 S2 明确标注的时间。
- **Lunch 未标注独立起止时间**。查询采用第 5 节结束到第 6 节开始的 12:10–14:10，查询涉及 Lunch 时说明这是一项依据前后课时边界采用的区间，并非学校明确公布的午休时间。
- **课间活动安排未明确**。课间由相邻已知课时边界确定，展示下一节的教室；不保证课间已经开放。
- **楼层和正式放学时间未明确**。不从教室编号猜楼层；按编号标识。查询最晚覆盖第 9 节结束 17:20，不将其表述为学校正式放学时间。
- 首节前、17:20 起、周末无数据，显示“当前时段暂无自习室安排数据”。
- 连续可用截至首次占用时段的开始；若一直空闲，则最晚到当日数据末尾。按该时间降序、相同时按编号排序，不延伸到无数据区间。

静态 JSON 在构建时直接打包进本地应用资源；沿用既有 SW 全资源预缓存。运行时不读取 Excel，不请求任何课表服务，Tauri 直接使用打包资源。首次网页缓存完成后可离线使用。

## 手动查询与上线提示

默认自动查询保持不变。手动模式改为“按课表查询”，选择周一至周五和第 1–9 节或午休，立即显示所选时段的可用教室；不再要求填写日期或起止时间，不需要额外提交。时段选项直接来自静态 JSON，周一首节会显示不同时间。

页面以教室编号和可用数量为重点，紧凑展示查询控件。每间教室显示“下时段有安排”或“下时段空闲，仍可用”，不再显示“可用至几点”。最后一节或后续缺少数据时显示“后续暂无安排数据”，不将未知状态推断为空闲；下一时段包括午休。排序仍优先显示连续空闲的教室。

查询按当前静态固定周课表匹配，不含节假日或临时调课。手动选择不会被 15 秒自动更新覆盖，切回自动模式立即显示当前结果。仅在用户切入按课表查询或改变星期、时段时记录固定事件 `tool.study-rooms.manual-query`，不发送选择值；组件刷新和自动计时不上报。

首页在新手向导关闭后展示“自习室查询已上线”，支持“知道了”和“去查自习室”。展示时写入 `sudubox.announcement.study-rooms.v1` 本地标记，刷新或返回首页不重复显示；不新增用户身份或跟踪 ID。由于项目没有账号，同一浏览器只展示一次，跨设备和清除存储后无法共享标记。存储被禁用时，本次应用会话内也不会重复弹出。

按用户要求已移除页面底部“作息与数据说明”区块，保留简短免责声明及查询涉及 Lunch 时的边界提示。

## 配置 Umami Cloud

推荐的简便方式：在 `src/data/analytics-config.json` 的 `websiteId` 中填写 Umami Website ID，保留 `hostname` 为 `suducat.github.io`，提交后由现有 Pages 工作流自动部署。Website ID 是公开的网站标识，不是密码或 API Key。留空时不加载统计。

也可使用以下 GitHub Actions 变量方式；构建变量非空时优先于 JSON 配置：

1. 在 Umami Cloud 官方控制台 `https://cloud.umami.is` 创建 Website，填入正式站点域名，复制 Website ID（UUID，不是 API key）。
2. 在 GitHub 仓库 **Settings → Secrets and variables → Actions → Variables** 新增仓库变量 `UMAMI_WEBSITE_ID`，值为该 UUID。
3. 默认只允许正式域名 `suducat.github.io`。若使用自定义域名，另设 `UMAMI_HOSTNAME` 为正式域名（不含协议、路径或端口）。
4. 重新运行现有 Pages 部署工作流。构建步骤会将上述变量传给 Vite；不改变部署平台。未填 Website ID 时不加载统计脚本。
5. 使用其他构建方式时，可将 `.env.example` 复制为 `.env.local` 并填写 `VITE_UMAMI_WEBSITE_ID` / `VITE_UMAMI_HOSTNAME`；变量需要在**构建时**提供。`npm run dev` 始终不统计。

在 Umami 官方后台选择网站：日期范围选“今天”查看 Visitors（独立访客）和 Views（浏览量）；调整日期范围及图表粒度查看日、周、月趋势；页面、设备、浏览器和 Events 可查看相应统计。工具页面以固定 hash 路径区分。无需在 SuduBox 中配置后台、API 密钥或显示公开计数。

在“外观与偏好 → 匿名使用统计”可关闭。偏好保存在当前浏览器，不随学习数据备份迁移。关闭后发送前检查立即拒绝后续请求；已发出的网络请求不能撤回。重新开启后若该页面曾移除尚未加载完成的脚本或脚本加载失败，刷新页面即可恢复；不自动重试或补报。浏览器的“请勿追踪”也会被官方脚本尊重。

## 事件约定与隐私

页面浏览：每次进入已知页面上报一次官方 pageview；工具打开：`tool.<工具ID>.open`。React 重渲染、StrictMode effect 再执行、时间更新、重复导航到同一页均不新增打开事件。离线期间的数据不存储、不补报；脚本加载前的操作也不排队。

| 核心事件 | 触发点 |
| --- | --- |
| `tool.schedule.save` / `tool.schedule.import` | 成功保存课程 / 导入 AIP 课表 |
| `tool.gpa.calculate` | 用户有效修改成绩或加入课程、触发本地计算；不在自动计算/render 中上报 |
| `tool.formulas.view` | 用户打开公式详情 |
| `tool.exams.save` | 成功保存考试倒计时 |
| `tool.focus.start` | 成功启动或恢复计时 |
| `tool.random.draw` | 成功抽题，覆盖题号、列表与题库卡片模式 |
| `tool.notes.create` | 成功创建便签 |
| `tool.text.clean` | 点击开始整理 |
| `tool.words.save` / `tool.words.import` | 成功保存单词 / 导入单词 |
| `tool.words.review` | 用户翻动复习卡片 |
| `tool.study-rooms.manual-query` | 切入按课表查询或更改星期、时段一次，不发送选择值 |
| `tool.study-rooms.query` | 每次进入自习室页面仅一次，15 秒刷新、焦点刷新均不上报 |

文件转换和 AI 检测在当前项目仍是“敬请期待”，仅记录打开次数，不虚构不存在的核心操作。

事件 API 只接受固定枚举，不接受内容或任意属性。发送前再次检查环境、联网及退出偏好，重建白名单 payload：固定页面路径、固定页面标题、固定事件名与官方常规浏览器字段；删除查询参数、来源 URL、输入、成绩、单词、便签、文件、额外属性和自定义身份字段。不调用 identify，不生成用户 ID、指纹或跨站追踪逻辑。设备/浏览器及匿名独立访客由 Umami 官方实现提供。

仅生产构建、HTTPS、指定正式域名、联网且非 Tauri 时启用。官方脚本异步加载，关闭自动采集、错误采集与性能采集，仅手动发送白名单事件；失败静默处理，无持久化、主动重试或补报。第三方脚本和请求不进入 SW 缓存，统计服务失效不影响本地工具。

## 验证记录与范围

- Python `--check` 核验全部 850 个状态、17 个编号、50 个时段与 S2 时间，含所有合并区域。
- 单元测试覆盖北京时间、周一首节、5 天全部课时边界、Lunch、课间、周末、末节后、连续可用排序与占用提醒。
- Hook 测试验证 15 秒跨节次、focus/visibility 更新及卸载清理。
- 统计测试覆盖未配置、离线、开发、Tauri、非正式域名、静默失败、不重试、不补报、重复导航、退出和字段白名单。
- `npm test`、`npm run build`、`node scripts/check-offline.mjs` 为验收命令；离线脚本模拟网络完全不可用，检查自习室数据所在 bundle 可从缓存命中，且 Umami 不预缓存、不被 SW 拦截。
- 浏览器生产预览检查深浅主题页面、首页卡片和设置开关；确认离线缓存就绪后关闭本地预览服务器，重新加载并打开自习室页面成功。未配置真实 Umami Website ID，未向真实后台发送验收数据；未在原生 iPad 或 Tauri 安装包上实机测试。
